## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to API | Reference role and asset IDs are user-controlled and must be validated. |
| API to provider status | Capability metadata is browser-visible and must not expose secrets. |
| Asset metadata to generation snapshot | Rights/source state must be copied without binary payloads or mutable assumptions. |

| T-11-02 | Information Disclosure | provider capability response | mitigate | Extend browser-safe capability metadata only; test that credential values never appear. |
| T-11-03 | Repudiation | rights/source snapshot | mitigate | Define immutable snapshot fields and schema version for later model-run/artifact/version persistence. |
