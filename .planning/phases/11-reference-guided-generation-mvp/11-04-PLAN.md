| Boundary | Description |
|----------|-------------|
| Worker to provider adapter | References may include user-uploaded assets and must be capability-gated. |
| Asset ledger to queued job | Rights/source metadata may change after enqueue, so worker must re-check. |
| Provider failure to durable metadata | Hosted errors must be sanitized before persistence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-10 | Elevation of Privilege | hosted reference input | mitigate | Require provider capability, feature flags, credentials, and hosted guards before sending reference inputs. |
| T-11-11 | Tampering | reference asset ownership | mitigate | Worker verifies each included asset belongs to the job workspace. |
| T-11-12 | Information Disclosure | provider request metadata | mitigate | Never embed binary image data, local paths, or secrets in request metadata; sanitize provider failures. |
</threat_model>
