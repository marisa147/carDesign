# Plan 18.02: Template-Aligned PreviewSpec Overlays And Warnings

## Goal

Make PreviewSpec text/logo layers reference safe zones that exist on the selected template and expose template warnings clearly in 2D preview.

## Tasks

1. Add core prompt helper logic that selects overlay zones from the brief's safe zones.
2. Add tests that text/logo overlay `zone_id` values are present in PreviewSpec safe zones for all MVP templates.
3. Update Workbench preview summary/legend to show template id and warning messages.
4. Add frontend coverage for a van PreviewSpec with template-specific safe zones.

## Acceptance

- PreviewSpec overlay layers never point to missing safe-zone ids when safe zones exist.
- Workbench displays selected template id/label/view and warnings from the selected version.
- Safe-zone labels and coordinates remain driven by PreviewSpec data.
