# Plan 18.01: Local Deterministic Generation On Every MVP Template

## Goal

Prove that every MVP template can generate through the local deterministic provider without hosted credentials.

## Tasks

1. Parameterize worker seed helpers by `vehicle_template_id`.
2. Run generation for every `MVP_TEMPLATE_IDS` record.
3. Assert artifact dimensions, PreviewSpec template id, safe-zone count, and overlay zones match the selected template.
4. Ensure local provider metadata includes the selected template context.

## Acceptance

- All MVP templates complete a local generation job.
- Generated artifact and version parameters preserve selected template id/view.
- No hosted provider configuration is required.
