# Plan 18.03: Targeted Edit Region And Mask Selection From Selected Template

## Goal

Ensure targeted edit selection uses the selected version's template safe zones and does not keep stale targets across version/template changes.

## Tasks

1. Clear selected edit target when the current PreviewSpec no longer contains it.
2. Assert safe-zone target selection sends the selected template region.
3. Assert overlay target selection resolves to the overlay's selected-template safe zone.
4. Extend worker recomposition tests with canonical template metadata and selected safe-zone evidence.

## Acceptance

- Mask preview and submitted edit intent use selected-template normalized coordinates.
- Stale selected targets are cleared when switching versions.
- Recomposition child metadata preserves template context.
