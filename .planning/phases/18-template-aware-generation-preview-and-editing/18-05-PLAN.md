# Plan 18.05: Lightweight 3D Shell Compatibility And 2D Fallback Per Template

## Goal

Resolve supported coupe template ids to the lightweight shell and keep unsupported MVP templates on explicit 2D fallback.

## Tasks

1. Add canonical `generic_coupe_side_v1` shell registry support while preserving legacy `generic-side-coupe`.
2. Keep fallback reasons template-specific for unsupported MVP templates.
3. Assert 3D warnings continue to say concept-only and UV-not-verified.
4. Add frontend compatibility tests for canonical coupe and van fallback.

## Acceptance

- Canonical and legacy coupe PreviewSpecs are compatible.
- Van and other unsupported templates show a selected-template fallback reason.
- UI does not contain production-ready claims.
