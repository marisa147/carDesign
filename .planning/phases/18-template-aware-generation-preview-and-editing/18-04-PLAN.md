# Plan 18.04: Reference And Provider Trace With Template Context

## Goal

Record template context beside reference roles, rights snapshots, provider, model, and cost metadata.

## Tasks

1. Add a worker helper that extracts concise template trace from PreviewSpec/prompt payload.
2. Include template trace in model run parameters and prompt payload where missing.
3. Include template trace in artifact metadata, version parameters, job operations, and final event metadata.
4. Extend reference trace regression tests to assert template context on all durable surfaces.

## Acceptance

- Reference-guided jobs persist template context on every durable trace surface.
- Provider/model metadata remains present and secret-free.
- Existing reference rights snapshots are unchanged except for added template context.
