# Phase 31 Plan: Section-First Design Workspace

## Implementation Steps

1. Template detail loading
   - Import `getTemplate` and `TemplateDetailResponse` in `WorkbenchApp`.
   - Load detail for selected/current brief template and keep it in state.
   - Clear stale detail when no template is selected.

2. Section selection state
   - Add selected section id local state in `ParameterPanel`.
   - Derive section rows from `templateDetail.sections`.
   - Add `onSectionSelect` callback from WorkbenchApp.

3. Targeted edit coupling
   - Selecting a section turns on targeted edit mode, sets selected view to the section's first view, and writes a normalized rectangle target from `section.bounds`.
   - Local edits and overlay mask preview now have a section-derived target before submission.

4. UI and tests
   - Add `分区工作台` panel with section list and flat panel metadata.
   - Extend TypeScript coverage and add focused test fixtures where possible.
