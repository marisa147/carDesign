# Plan 20.02: Docker And Local Smoke Evidence

## Goal

Verify the local deterministic stack and smoke command surface without hosted credentials.

## Tasks

1. Check Docker daemon availability.
2. Run `pnpm smoke:local` with Compose management if Docker is available.
3. Run `pnpm smoke:worker -- --dry-run`.
4. Record pass/fail evidence and cleanup state in `20-DOCKER-SMOKE.md`.

## Acceptance

- Docker-backed smoke is passed or honestly blocked by host prerequisites.
- Worker smoke dry run passes.
- No real provider calls or secrets are used.
