<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User/API to job state | User-controlled cancellation request changes durable job state |
| API to Celery broker | Best-effort revoke crosses process boundary |
| Worker to storage/provider | Worker must stop before expensive side effects when canceled |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-09 | Tampering | cancel route | mitigate | Only allow valid queued/running state transitions through core validation. |
| T-07-10 | Repudiation | cancellation event | mitigate | Persist source, reason, requester, queue revoke status, and timestamp through job events. |
| T-07-11 | Denial of Service | revoke failures | mitigate | Treat broker revoke as best-effort and keep durable state authoritative. |
</threat_model>
