<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Environment config to API response | Secret-backed provider settings become operator-visible summaries |
| Celery broker to API response | Live queue inspection may fail or return stale worker information |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03 | Information Disclosure | operations endpoint | mitigate | Return secret presence booleans only; tests assert no configured secret appears in JSON. |
| T-07-04 | Spoofing | worker inspection | mitigate | Label queue inspection as best-effort and keep durable job state canonical. |
| T-07-05 | Denial of Service | Celery inspect | mitigate | Use short timeout and degrade to `unavailable` rather than blocking API health. |
</threat_model>
