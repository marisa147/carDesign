<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| environment -> worker process | Env vars configure Redis, runtime mode, and provider key entries. |
| worker -> Redis broker | Celery boot uses broker configuration but does not create durable product state. |
| worker code -> API package | Worker must not import FastAPI routers or backend internals. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01C | Information Disclosure | worker settings | mitigate | Store provider keys as `SecretStr`, do not log secret values, and test redaction. |
| T-01-02C | Information Disclosure / Elevation | worker imports | mitigate | Worker imports only `caragent_worker` modules and Celery; tests scan for `caragent_api` and `FastAPI` imports in worker source. |
| T-01-05C | Tampering | worker docs | mitigate | README labels Redis broker defaults as local-only and states product jobs/provider calls are outside Phase 1. |
</threat_model>
