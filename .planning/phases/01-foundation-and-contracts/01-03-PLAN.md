<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API source -> generated OpenAPI | Backend code produces schema consumed by frontend. |
| generated contract package -> browser bundle | Frontend imports TypeScript client code and must not import Python internals. |
| developer changes -> contract drift check | Unsafe API changes must not be hidden by stale generated artifacts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02C | Information Disclosure / Elevation | `packages/contracts` exports | mitigate | Export generated OpenAPI client/models only; add a test/static scan that package source does not import from `services/api` or reference provider key env vars. |
| T-01-04C | Tampering / Repudiation | `contracts:check` | mitigate | Implement deterministic generate-then-diff check that exits non-zero when `packages/contracts/openapi` or `packages/contracts/src/generated` changes. |
| T-01-01C | Information Disclosure | generated contract artifacts | mitigate | Ensure generated OpenAPI contains schema/route metadata only and no configured secret values; tests assert provider key env var names are absent from `openapi.json`. |

No high severity threat is left unmitigated in this plan.
</threat_model>
