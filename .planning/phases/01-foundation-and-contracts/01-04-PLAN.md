<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer env file -> app and Compose processes | Example values configure local services and app settings. |
| host network -> local service ports | PostgreSQL, Redis, and MinIO ports are published for local development. |
| local docs -> operator assumptions | Docs must not imply local defaults are production safe. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01D | Information Disclosure | `.env.example` files | mitigate | Commit example files only; use empty provider key entries and local-only S3 example values; add `check-env-examples.mjs` to fail on real-looking secrets or missing required names. |
| T-01-03D | Information Disclosure / Tampering | `CORS_ORIGINS` examples | mitigate | Default CORS examples to `http://localhost:3000` and `http://127.0.0.1:3000`, not `"*"`. |
| T-01-05D | Information Disclosure / Tampering | `infra/compose.yml` and `infra/README.md` | mitigate | Bind documented local ports, use local-only credentials, add health checks, and state these settings are not a production deployment recipe. |

No high severity threat is left unmitigated in this plan.
</threat_model>
