<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend schema -> committed OpenAPI | API shape becomes a repo artifact. |
| generated client -> browser code | Frontend consumes generated functions and types. |
| git diff -> validation result | Drift script decides whether generated artifacts are current. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04F | Tampering / Repudiation | `scripts/check-contracts.mjs` | mitigate | Regenerate OpenAPI and TypeScript artifacts, then fail if `git diff --exit-code` reports changes under `packages/contracts/openapi` or `packages/contracts/src/generated`. |
| T-01-02F | Information Disclosure | generated client | mitigate | Validate generated client is derived only from `/health` and does not include provider secret env names or backend file paths. |
</threat_model>
