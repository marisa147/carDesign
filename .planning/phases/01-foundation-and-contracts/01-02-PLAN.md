<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/client -> API | Future frontend calls `/health`; API must expose only typed safe data. |
| environment -> API process | Env vars configure DB, Redis, S3, CORS, runtime mode, and provider key entries. |
| API code -> contracts package | OpenAPI export becomes the source consumed by TypeScript generation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01B | Information Disclosure | API settings | mitigate | Store provider keys as `SecretStr`, do not log secret values, and test that settings string output excludes raw secrets. |
| T-01-03B | Tampering / Information Disclosure | CORS middleware | mitigate | Parse `CORS_ORIGINS` into explicit origins; reject `"*"` when runtime mode is not `local` or when credentials are enabled. |
| T-01-04B | Tampering / Repudiation | OpenAPI export | mitigate | Provide deterministic `export_openapi.py` CLI so contracts can be regenerated and compared by plan `01-06`. |
</threat_model>
