<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> API | Health-check CTA calls the API base URL through generated contracts. |
| frontend env -> browser bundle | Only `NEXT_PUBLIC_API_BASE_URL` can be exposed to the browser. |
| generated contracts -> UI | UI consumes generated TypeScript package rather than backend Python internals. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02E | Information Disclosure / Elevation | `apps/web/src/**` imports and env reads | mitigate | Add tests/static checks that web source imports `@caragent/contracts` for health and does not reference `AI_PROVIDER_`, `S3_SECRET_ACCESS_KEY`, `DATABASE_URL`, `REDIS_URL`, or `services/api`. |
| T-01-04E | Tampering / Repudiation | health client wrapper | mitigate | Health wrapper uses generated contract exports from `@caragent/contracts`; frontend tests fail if the generated import is removed. |
| T-01-05E | Information Disclosure | shell copy | mitigate | UI copy states only foundation checks are available and labels future regions `后续阶段开放`; no production or generation workflow is implied. |

No high severity threat is left unmitigated in this plan.
</threat_model>
