# Plan 17.01: Template Catalog API Schemas And List/Detail Endpoints

## Goal

Expose MVP templates through typed API responses that contain id, label, supported views, thumbnail URL, safe-zone summary, source/license metadata, readiness flags, warnings, and blocking reasons.

## Tasks

1. Add template catalog response schemas.
2. Add `GET /templates` with optional view/readiness filtering.
3. Add `GET /templates/{template_id}` that accepts canonical ids and legacy aliases.
4. Return stable 404 detail for unknown template ids.
5. Add API tests and OpenAPI path coverage.

## Acceptance

- API lists all five MVP templates.
- Detail endpoint resolves `generic-side-coupe` to canonical coupe metadata.
- Responses include thumbnail URLs, source/license state, readiness, and safe-zone summary.
