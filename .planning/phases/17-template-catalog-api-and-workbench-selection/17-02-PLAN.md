# Plan 17.02: Template Thumbnail Serving

## Goal

Serve deterministic template thumbnails through API URLs that the Workbench catalog can render.

## Tasks

1. Add `GET /templates/{template_id}/thumbnail.png`.
2. Read thumbnail PNG bytes from the package resource using the template registry.
3. Return image/png and stable 404 responses for unknown or missing assets.
4. Add API tests that verify PNG response headers and signature.

## Acceptance

- Every catalog item has a thumbnail URL that returns PNG bytes.
- Unknown template ids do not leak filesystem paths.
