# Plan 17.05: Workbench Template Selector UX

## Goal

Expose a compact template catalog selector in the parameter panel with thumbnails, filtering, readiness states, source/license warnings, and stable fallback messages.

## Tasks

1. Add a catalog selector to the parameter panel.
2. Show thumbnails, template labels, source/license status, and readiness badges.
3. Disable non-catalog-ready options and display blocking reasons/warnings.
4. Persist selection through `PATCH /generation/briefs/{brief_id}` when a brief exists.
5. Add Workbench tests for browsing, selecting, and request payloads.

## Acceptance

- Users can filter and select coupe, sedan, hatchback, SUV, or van.
- Selected template appears in the parameter panel and subsequent brief payloads.
- Warnings and unavailable states are visible before submission.
