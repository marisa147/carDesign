# Plan 17.03: Brief Template Update And Persistence

## Goal

Allow selected template changes to recompute and persist the generation brief payload, then carry template context into generation job metadata.

## Tasks

1. Add `vehicle_template_id` and `view` to `GenerationBriefUpdateRequest`.
2. Re-resolve template metadata when a brief update changes template id or view.
3. Keep fallback warnings stable for unsupported template/view inputs.
4. Persist selected template summary in generation job metadata.
5. Add API tests for brief patch and job metadata.

## Acceptance

- Updating a brief to `generic_van_side_v1` changes id, label, source/readiness, and safe zones.
- Unsupported updates normalize to the default template with warnings.
- Submitted jobs include selected template metadata.
