# Plan 17.04: Frontend Catalog API Client And State

## Goal

Add typed frontend helpers and Workbench state for loading templates, remembering selected template id, and passing selection into brief create/update calls.

## Tasks

1. Regenerate contracts after API changes.
2. Add frontend template API wrapper and tests.
3. Add template query key and Workbench state for selected template id.
4. Load templates on Workbench start and cache them.
5. Include selected template id/view when creating briefs.

## Acceptance

- Frontend tests cover template API wrapper and request paths.
- New chat submissions include selected template id.
- Resumed briefs restore selected template state.
