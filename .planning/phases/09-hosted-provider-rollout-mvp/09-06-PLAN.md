## Trust Boundaries

| Boundary | Description |

| User provider selection to API payload | Browser can request intent, but server remains authoritative. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-09-17 | Denial of Wallet | accidental hosted submit | mitigate | Disable hosted submit when preflight/operations state is blocked and keep local option visible. |
</threat_model>
