<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to API | Edit target and mask metadata are user-controlled and must be validated. |
| API route to job metadata | Parent lineage is route-derived and must not be spoofed by request body. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | edit intent metadata | mitigate | Validate route/mode/target/region with typed schemas and tests. |
| T-10-02 | Elevation of Privilege | parent version lineage | mitigate | Derive `parent_version_id` from the version-scoped route and ignore conflicting client metadata. |
| T-10-03 | Information Disclosure | mask/provider metadata | mitigate | Store mask references and safe provider parameters only; never persist raw secrets or binary mask payloads in job JSON. |
</threat_model>
