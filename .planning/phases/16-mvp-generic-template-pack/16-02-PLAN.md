# Plan 16.02: Deterministic Internal Asset Generation

## Goal

Create internal-original PNG assets and JSON metadata for coupe, sedan, hatchback, SUV, and van without relying on external vehicle imagery.

## Tasks

1. Add a deterministic asset generator script for the MVP template pack.
2. Generate required asset slots for each template:
   - `base.png`
   - `body_mask.png`
   - `window_mask.png`
   - `wheel_mask.png`
   - `handle_mask.png`
   - `panel_lines.png`
   - `safe_zones.json`
   - `template.json`
   - `thumbnail.png`
3. Use simple geometric silhouettes and normalized template specs to avoid unauthorized imagery.
4. Keep output dimensions stable and reproducible.

## Acceptance

- Every MVP template has all required asset files.
- Thumbnails are deterministic and differ by vehicle family.
- Source metadata identifies every template as internal original.
