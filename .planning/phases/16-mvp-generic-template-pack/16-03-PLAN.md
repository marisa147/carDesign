# Plan 16.03: Template Package Validation Command

## Goal

Provide a single command that validates the physical template package structure and metadata.

## Tasks

1. Add a core validation script entrypoint runnable with `python -m`.
2. Validate required asset slot presence for every template.
3. Validate PNG dimensions for full-size assets and thumbnails.
4. Validate safe-zone coordinates are normalized and inside canvas bounds.
5. Validate metadata can instantiate `VehicleTemplateRecord` and passes registry readiness.

## Acceptance

- One command exits 0 for the committed template pack.
- Validator reports clear template id and slot names on failure.
- Tests or verification run the command.
