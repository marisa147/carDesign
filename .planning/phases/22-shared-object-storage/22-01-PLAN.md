# Phase 22 Plan 01: Shared Storage Contract And Factory

## Objective

Make API and Worker storage behavior consistent across local file storage and S3-compatible storage, with contract tests proving bytes and content type round-trip through the same object key.

## Tasks

1. Extend the shared storage protocol with `head_object()` and `delete_object()`.
2. Add `StorageSettings` plus `ObjectStorageFactory.from_settings()` for API and Worker settings objects.
3. Make `FileObjectStorage` preserve content type through sidecar metadata and reject path traversal object keys.
4. Add `S3ObjectStorage` backed by a boto3-compatible client, with test injection for fake S3 clients.
5. Ensure API and Worker both use the shared factory and no longer hardcode old local roots.
6. Verify workspace-scoped artifact content streaming still rejects cross-workspace reads.
7. Run focused core/API/Worker checks and full `pnpm validate`.

## Acceptance

- Local file storage returns the original content type from `get_object()` and `head_object()`.
- S3-compatible storage contract test covers put/get/head/delete without real network access.
- API and Worker settings expose the same `OBJECT_STORAGE_BACKEND` and `OBJECT_STORAGE_LOCAL_ROOT` knobs.
- Final `pnpm validate` passes.
