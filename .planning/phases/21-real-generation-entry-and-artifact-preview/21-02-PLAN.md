# Plan 21.02: Artifact Content API And Generated Contracts

<objective>
Expose a stable workspace-scoped content URL on artifact responses and stream artifact bytes through the API.
</objective>

<threat_model>
- T-21-03: Cross-workspace artifact reads leak generated images. Mitigation: route checks `artifact.workspace_id == workspace_id` before storage read.
- T-21-04: Incorrect MIME type causes browser preview failures. Mitigation: response uses artifact content type, then stored content type, then `application/octet-stream`.
- T-21-05: Missing object bytes produce misleading success. Mitigation: storage `FileNotFoundError` returns 404.
</threat_model>

<tasks>

<read_first>
- `services/api/src/caragent_api/schemas.py`
- `services/api/src/caragent_api/routes/jobs.py`
