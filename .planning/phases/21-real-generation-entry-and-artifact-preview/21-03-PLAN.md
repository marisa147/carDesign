# Plan 21.03: 2D Image Preview And Resumed Artifact Visibility

<objective>
Render generated artifact bytes as a real 2D image in the preview panel and make resumed workspaces show the latest generated image.
</objective>

<threat_model>
- T-21-06: Preview uses a scaffold drawing while real artifact bytes exist. Mitigation: render artifact `content_url` as `<img>` whenever available.
- T-21-07: Relative API routes break in the browser. Mitigation: prefix relative `content_url` with `publicEnv.apiBaseUrl`.
- T-21-08: Resumed workspace shows jobs but not latest artifacts. Mitigation: resume flow loads latest job generation state.
</threat_model>

<tasks>
<task id="21.03.01" type="execute">
<read_first>
- `apps/web/src/components/workbench/preview-panel.tsx`
- `apps/web/src/lib/config/public-env.ts`
</read_first>
<action>
In `preview-panel.tsx`, add `artifactContentUrl(artifact)` that reads `artifact?.content_url`, returns absolute URLs unchanged, and returns `${publicEnv.apiBaseUrl}${contentUrl}` for relative routes. Use this value as `conceptImageUrl`.
</action>
<acceptance_criteria>

</acceptance_criteria>
</task>
