# Plan 21.01: Workbench Generation Entry And Active Polling

<objective>
Add the explicit workbench `生成概念` action and refresh queued/running generation jobs from durable API state every 1-2 seconds.
</objective>

<threat_model>
- T-21-01: Submitting without an active workspace or brief creates orphaned jobs. Mitigation: guard `onGenerate`/`handleGenerateConcept` when `workspace` or `currentBrief` is null.
- T-21-02: Polling continues after terminal status and creates avoidable API load. Mitigation: only poll `queued` and `running` jobs.
- T-21-03: Dirty parameters are skipped when generation starts. Mitigation: `ParameterPanel` saves `updatePayload` before calling `onGenerate`.
</threat_model>
