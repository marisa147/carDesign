# Plan 19.02: Version-Scoped Preflight API And Durable Report Artifact

## Goal

Let the Workbench request a preflight report for a selected version and persist the report in the existing export ledger.

## Tasks

1. Add a version-scoped API route that builds the preflight report.
2. Persist the report JSON as an `export` artifact.
3. Record an export row with format `production_readiness_preflight`.
4. Regenerate OpenAPI/TypeScript contracts and add API tests.

## Acceptance

- API returns report plus export metadata.
- The JSON report is stored in object storage.
- Listing exports shows the preflight record.
