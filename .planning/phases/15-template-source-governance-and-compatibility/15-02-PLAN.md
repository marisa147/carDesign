<objective>
Add a validated in-process template registry that records source, license, usage scope, distribution, and audit data for every reusable template.
</objective>

<tasks>
1. Add `VehicleTemplateRecord` and `TemplateRegistry`.
2. Require audit timestamp and reusable license/source status during registration.
3. Add `audit_vehicle_templates()` for operator-facing readiness review.
4. Cover successful and rejected registration paths in tests.
</tasks>

<verification>

- `uv run mypy src`
</verification>

<success_criteria>
- Operators can register allowed template records.
- Operators can inspect audit items without reading internal registry state.
</success_criteria>

<threat_model>
Registry validation prevents unsafe reusable assets from entering downstream catalog or generation flows. It does not store secrets and must not expose binary asset content.
</threat_model>
