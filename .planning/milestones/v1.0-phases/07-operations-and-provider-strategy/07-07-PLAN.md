|----------|-------------|

| Browser cancel action to API/worker | User action changes durable job state and queue behavior |
| Smoke scripts to local services | Verification scripts coordinate Docker, API, worker, and DB state |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07-19 | Tampering | cancel UI | mitigate | UI calls typed API route; backend enforces state transitions. |
| T-07-20 | Denial of Service | smoke worker process | mitigate | Use documented solo worker mode and dry-run path; ensure scripts terminate child processes they start. |
</threat_model>
