<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer machine -> local containers | Compose publishes PostgreSQL, Redis, and MinIO ports for local development. |
| env examples -> runtime config | Example values feed API, worker, web, and Compose settings. |
| smoke script -> local network | Smoke runner probes local services and must not call providers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01D | Information Disclosure | `.env.example` files | mitigate | Commit example values only, scan for real-looking secret values, and keep real env files ignored from plan `01-01`. |
| T-01-05D | Information Disclosure / Tampering | `infra/compose.yml` | mitigate | Bind local service defaults through configurable ports and label credentials/ports as local-only in `infra/README.md`. |
| T-01-04D | Repudiation | smoke result | mitigate | Make smoke script explicit about Docker daemon availability and return a failing code only when Docker is available and service checks fail. |
</threat_model>
