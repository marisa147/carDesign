```typescript
export type DependencyHealthStatus =
  | "ok"             // live check or local API-owned self-check actually succeeded
  | "configured"     // config value exists, but live dependency probe was not performed here
  | "unavailable"    // live probe failed, or smoke/local dependency is unavailable
  | "not_configured";
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API `/health` -> browser UI | Users trust health response statuses to reflect the level of validation actually performed. |
| developer shell -> Docker daemon/local services | `smoke-local` decides whether Docker-backed services were actually checked. |
| FastAPI schema -> generated TypeScript client | Health schema changes must propagate to frontend types. |
